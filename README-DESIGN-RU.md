# NEXORA — SIGNAL DESIGN

Редизайн выполнен по трём изображениям из папки «стиль пример сайтов»: выразительная типографика, асимметрия и объёмный акцент переосмыслены для рабочего SaaS-интерфейса. Цвета и композиции референсов не копировались.

## Что обновлено

- Общая палитра: графитовый зелёный, холодный белый, мятный акцент. Контрастные верхние блоки и спокойные рабочие поверхности.
- Заново собраны обзор бизнеса и экран входа; декоративный объёмный знак строится средствами CSS, без внешних картинок и библиотек.
- Единая навигация во всех кабинетах, выбранная компания сохраняется в ссылках.
- Новый стиль каталога, базы знаний, заявок, аналитики, подключения, онбординга и обоих чатов.
- Мобильное меню с закрытием по Escape, возвратом фокуса и ограничением навигации клавиатурой внутри открытого меню.
- Состояния кнопок и полей, мягкое появление экранов, поддержка prefers-reduced-motion.
- Таблица заявок прокручивается внутри собственного блока; страница не расширяется.
- Исправлены устаревшие подписи о неиспользовании Gemini и неподключённых возможностях.

## Как установить в существующий проект

1. Остановите runserver и сохраните копию своей папки проекта.
2. Откройте папку nexora внутри архива. Скопируйте её содержимое в текущую папку NEXORA-AI, рядом с manage.py, с заменой файлов. Не создавайте вложенную папку NEXORA-AI/nexora.
3. Сохраните свою .env, базу данных и .venv. В архиве нет базы, её резервных копий и секретов.
4. Запустите привычным интерпретатором:

```powershell
python manage.py check
python manage.py test
python manage.py runserver
```

5. Откройте /accounts/login/ и обновите браузер через Ctrl+F5. При необходимости очистите кеш статики. На production выполните штатный collectstatic и перезапуск приложения.

Зависимости, Python-код, Gemini, модели, маршруты и миграции относительно присланного проекта не изменялись. Новых миграций для дизайна нет. На чистой установке примените уже существующие миграции обычным migrate.

## Проверки

Выполнены 116 автоматических тестов проекта. В Chromium проверены 11 адресов кабинета на ширинах 360, 390 и 768 px, а также страницы публичного чата и входа: 35 проверок без горизонтального расширения страницы и без JS-ошибок. Отдельно пройдены создание и редактирование позиции каталога, добавление знания, создание клиентской заявки и её поиск владельцем. Проверены кнопка каталога и сохранение переписки после обновления.

Использовалась отдельная синтетическая база. Настоящий Gemini при проверках дизайна не вызывался. Safari и реальные телефоны отдельно не проверялись. Результаты: docs/DESIGN-BROWSER.json, docs/DESIGN-FLOW.json и docs/DESIGN-TESTS.log.
